## Carte du code Platyplus (Lua 5.1, commentaires en français)

Lire ceci au lieu de relire les gros fichiers. Les numéros de ligne bougent : les retrouver par Grep `-n`. Tenir cette carte à jour quand un module, un widget ou une recette change.

Dossier : `...\AddOns\Platyplus`. Ordre de chargement = `Platyplus.toc`. Chaque fichier commence par `local ADDON, ns = ...`.
Ignorer : `DungeonJournal/` (absent de la version publique ; généré par `dev/make_dungeonjournal.py` depuis `AddOns/ForeverDungeonJournal`, jamais modifié à la main), `dev/ancienne_carte/`, `Traducteur/` (programme Python compagnon), `Media/`.
Outils : `python -I dev\i18n.py extraire|manque|ajouter|verifier` (traductions, §8) · `python -I dev\verifier.py [filtre]` (syntaxe + tests, bilan court, §6) · `python -I dev\api.py <Nom>` (doc API Forever) · `python -I dev\wago.py <Table> <x>` (données client) · `python -I dev\apercu.py` (aperçus HTML).

Données : `ns.version`, `ns.MEDIA` (chemin Media\\), `ns.LOGO`, `ns.THEME` (L15 : bg, panel, card, line, accent, accent2, gold, good, bad, text, dim), `ns.SOURCES` (L30 : couleur/label des sources du flux), `ns.DEFAULTS` (L45-264, table locale `DEFAULTS` exposée).

- **Ajouter un réglage** : une entrée dans `DEFAULTS` (par section, avec commentaire), puis carte dans UIPages. Si la clé est une liste à garder lors de "tout réinitialiser" : l'ajouter à `LISTS` (L~378 ; y sont `neverSell`, `alwaysSell`, `procExtra`, `procIgnore`...).
- **Modes prêts à l'emploi** (après `ResetAll`) : `ns.MODES` = recommended (= DEFAULTS), complete, immersive, minimal (`off=true` : tout `MODE_KEYS` coupé sauf son `set`) ; chaque mode = `set` (écarts aux DEFAULTS) + textes FR (name/desc/tip). `ns.ModeKeys()` = clés réglées (MODE_KEYS + clés des `set`, booléens seulement), `ns:ModeValue(mode,key)`, `ns:CurrentMode()` (mode dont toutes les valeurs correspondent, sinon nil = « personnalisé »), `ns:ApplyMode(id)` (refusé en combat ; écrit tout puis notifie, comme ResetAll ; `db.mode` = base). Jamais la touche, les listes, positions, tailles, couleurs. Nouvelle fonction = l'ajouter à `MODE_KEYS` (et au `set` des modes qui la veulent autrement). `/pp mode [nom]`.
- Aides : `ns:Print(...)` (préfixe bleu), `ns:Debug(...)` (si db.debug), `ns:Set(key,val)` (écrit + notifie : TOUJOURS passer par là), `ns:OnChange(key|"*", fn(key,val))` (pcall), `ns:Notify(key)`, `ns:Reset(key)`, `ns:ResetAll(keepLists)` (remet tout à DEFAULTS, notifie chaque clé), `ns.Copy(v)` (copie profonde).
- **Enregistrer un module** : fichier dans le TOC, `local M = {}; ns.X = M`, méthode `function M:Init()`, ET ajouter `"X"` à la liste `for _, module in ipairs({...})` en fin de Core.lua (L~780) : appelle `ns[module]:Init()` si présent, dans cet ordre (UI en dernier). Pas de helper d'événements partagé : chaque module fait `CreateFrame("Frame")` + `RegisterEvent` (souvent `pcall(f.RegisterEvent, f, ev)`) + `SetScript("OnEvent")`, et réagit aux réglages via `ns:OnChange`.

Documenter aussi dans `printHelp()` (Core ~L353) et dans `COMMANDS` de UIPages (L2030, liste de l'onglet Avancé).
