# Lexique du traducteur Platyplus
#
# Une ligne par terme :   écriture 1 / écriture 2 / ... = ce que ça veut dire
# Majuscules et minuscules : peu importe. Les lignes qui commencent par # sont ignorées.
# Un « ! » devant une écriture : seulement si elle est écrite en majuscules
# (« !IF » = Forgefer, mais pas le mot anglais « if »).
# Quand un message contient un de ces termes, le traducteur donne le sens à l'IA,
# qui comprend alors « WC » ou « oom » au lieu de deviner.
# Si un message tient entièrement dans le lexique (« ty », « brb »), il est traduit
# tout de suite, sans l'IA. Tu peux ajouter tes propres lignes : elles comptent
# au prochain lancement du traducteur.
